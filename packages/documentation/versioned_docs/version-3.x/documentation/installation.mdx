# Installation

> Note: React 16.8+ is required to use Hooks.

## Package Managers {#yarn--npm}

To install the package we use our favorite package manager.

<Tabs
  defaultValue="pnpm"
  values={[
    { label: 'pnpm', value: 'pnpm' },
    { label: 'bun', value: 'bun' },
    { label: 'npm', value: 'npm' },
    { label: 'yarn', value: 'yarn' },
  ]}
>
  <TabItem value="pnpm">
    <CodeBlock className="language-shell">pnpm add react-hotkeys-hook@3</CodeBlock>
  </TabItem>
  <TabItem value="bun">
    <CodeBlock className="language-shell">bun add react-hotkeys-hook@3</CodeBlock>
  </TabItem>
  <TabItem value="npm">
    <CodeBlock className="language-shell">npm i react-hotkeys-hook@3 --save</CodeBlock>
  </TabItem>
  <TabItem value="yarn">
    <CodeBlock className="language-shell">yarn add react-hotkeys-hook@3</CodeBlock>
  </TabItem>
</Tabs>

## ES Module

To use the ES Module we can reference it directly from [unpkg.com](https://unpkg.com):

```js
import { useHotkeys } from 'https://unpkg.com/browse/react-hotkeys-hook@3.4.0/dist/react-hotkeys-hook.esm.js'
```

## Direct CommonJS Module

We also have access to a development as well as a minified production bundle for CommonJS:

<Tabs
  defaultValue="development"
  values={[
    { label: 'Development', value: 'development' },
    { label: 'Production', value: 'production' },
  ]}
>
  <TabItem value="development">
    <CodeBlock className="language-html">
      {'<script src="https://unpkg.com/browse/react-hotkeys-hook@3.4.0/dist/react-hotkeys-hook.cjs.development.js"/>'}
    </CodeBlock>
  </TabItem>
  <TabItem value="production">
    <CodeBlock className="language-html">
      {
        '<script src="https://unpkg.com/browse/react-hotkeys-hook@3.4.0/dist/react-hotkeys-hook.cjs.production.min.js"/>'
      }
    </CodeBlock>
  </TabItem>
</Tabs>

---

Now we are good to go to use the hook.
